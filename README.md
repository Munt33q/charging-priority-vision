# Charging-Station Emergency-Vehicle Priority (Vision)

YOLO-based vision system that detects vehicles at a charging station and
assigns a 4-tier charging priority:

> **Repository:** this project contains the reproducible code and demo. Large
> datasets and model checkpoints are intentionally excluded; see
> [MODEL_AUDIT.md](MODEL_AUDIT.md) for the completed Kaggle evaluation and
> limitations.

| Tier | Vehicle type | Classes |
|---|---|---|
| **0 (highest)** | Emergency vehicles | ambulance, fire_truck, police |
| 1 | Cars | car, pickup_truck, work_van |
| 2 | Semi trucks | semi_truck (articulated) |
| 3 (lowest) | Trucks | truck (single unit) |

## Datasets used

| Dataset | Source | Size | Role |
|---|---|---|---|
| MIO-TCD Localization | official tar / Kaggle mirror `mzare21/mio-tcd-yolo` | 137,743 imgs | car / semi_truck (articulated) / truck (single-unit) / pickup / van |
| Emergency Vehicle Detection v3 | Kaggle `prachiii33/dataset` (Roboflow, CC BY 4.0) | 9,043 imgs | ambulance, fire_truck, police, car |
| DAWN (adverse weather) | Kaggle `orvile/dawn-detection-in-adverse-weather-nature` (CC BY-NC 4.0) | 1,009 imgs | real fog/rain/snow/sand examples |
| synthetic weather | generated by `scripts/weather_aug.py` | 35% of train | rain, fog, night, glare, blur, noise, droplets |

## Pipeline

```
data/raw        downloaded archives (kaggle_client.py / direct)
data/processed  per-dataset YOLO conversions (scripts 01-03)
data/dataset    merged train/val/test split (script 04)
scripts/05      weather augmentation of train images only
scripts/06      YOLO training (ultralytics, config.yaml)
scripts/07      test-split evaluation -> reports/eval_report.md
scripts/08      priority assignment + live/image inference
```

## Usage

```bash
python scripts/run_all.py          # full pipeline
python scripts/run_all.py 6        # resume from step 6 (train)

# inference on an image or webcam
python scripts/08_priority.py path/to/image.jpg
python scripts/08_priority.py 0    # webcam index 0

# reproducible demo (requires a downloaded trained best.pt)
python scripts/demo.py --source path/to/image.jpg --weights path/to/best.pt
python scripts/demo.py --source path/to/video.mp4 --weights path/to/best.pt --output demo.mp4
```

## Notes / caveats

- Tier mapping is configurable in `config.yaml` (TIER_MAP).
- MIO-TCD license is CC BY-NC-SA 4.0 (non-commercial); DAWN is CC BY-NC 4.0.
- "Emergency" here means the vehicle *type* - a tier-0 vehicle gets priority
  whether or not it is actively responding to an emergency.
- Site-specific camera footage should be added later for domain adaptation;
  keep separate recording sessions in separate splits.
